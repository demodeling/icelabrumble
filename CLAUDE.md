# CLAUDE.md — house rules for working on IceLab Rumble

## What this is
A single-page HTML5 canvas fighting game (the IceLab crew vs a false-positive rhino), deployed to GitHub Pages by the workflow in `.github/workflows/pages.yml`.

## Layout
- `src/index.html` — the whole game (CSS + JS in one file). The tokens `__VIDEOS__`, `__APPVER__` (package.json version, shown on the title screen) and `__VERSION__` (git hash) are replaced by `tools/build.py`; never hardcode them. Bump `"version"` in `package.json` when releasing.
- `src/vendor/trystero.js` — Trystero (WebRTC + Nostr signalling) bundled as one ES module for co-op; regenerate with `npm run vendor`. Imported on demand by `netTransport()`.
- `src/sw.js`, `src/manifest.webmanifest`, `src/icons/` — installable web-app bits. `__VERSION__` in sw.js is replaced at build time. The page, scripts and manifest are network-first (cache = offline fallback); videos/icons cache-first. The page reloads itself once when a new worker takes over while on the title screen. Fullscreen: native Fullscreen API where it exists (iPhone from iOS 16.4) with a landscape lock attempt, CSS rotation (`fs-rot`) as the portrait fallback — the request goes to `document.documentElement` (`FS_EL`), never `#stage`, because the browser's own `:fullscreen` style would override the rotation; iPhones not installed as an app get a Home Screen hint on the title screen.
- `assets/videos/intro.mp4` — the only clip: the menu video ("False positive: a real sequence, the wrong label", rhino turns into a zebra) from `tools/video/render_intro.sh` (`CHAR` = a roster id, `SHIRT` = its jacket colour; the sprites come from `node export_sprites.js <id>`). `tools/build.py` copies `CLIPS` = `['intro']`. There are no per-fighter videos — do not add any.
- `tools/build.py` — assembles `dist/`. `--inline` embeds the menu clip as base64 (single-file build for claude.ai artifacts).
- `tests/smoke.spec.js` — Playwright smoke test. Keep it green.

## How to work
1. `npm install && npx playwright install chromium` once.
2. Edit `src/index.html`. Run `npm test` (builds, then tests). Run `npm run serve` and open http://localhost:8000 to play.
3. Commit to `main` and push; the Action tests, builds and deploys. The live site updates in 1–2 minutes.

## Rules of thumb
- Safari first: no optional chaining or `??` in page JS, Web Audio only after a user gesture (`unlockAudio()`), pointer events for touch buttons.
- Input: a focused control keeps its own keyboard — `typingIn()` (text fields) swallows everything, `ownsKeys()` (button, select, link) declines to steer the fighter so Space, Enter and the arrows still work the UI. A `keyup` ALWAYS releases its key whatever has focus, `clearKeys()` runs on blur and at the start of every fight, and `blurFocus()` stops a just-clicked button eating the controls (FULLSCREEN blurs itself mid-fight). The touch pads (`.tb`) carry `touch-action:none`, or a thumb drifting ~15 px turns into a pan and `pointercancel` drops the held key; they must never overlap at any phone width (narrow portrait tightens the gaps, and under 350 px DUCK moves above the arrows).
- Hit boxes: `rhinoAt(pt, pad, k)` widens its vertical pad for a short target (`165 * k - height`, k = the attacker's size, so a grown round-5 fighter can still punch a small rhino; the duel `foeAt()` does the same for a fighter), and nothing lands once `G.over` (guards in `hitRhino`, `hitFoe`, `hitEnt`, `hitPlayer`: an attack in flight at the bell must not change a verdict); a prop (`stickPt`) is tried *before* the fist and falls back to it, never replaces it. `clampLevel()` guards every assignment to `LEVEL`, including the one from a peer's `start` message.
- Keep `dist/` out of git; it is a build product. `docs/` IS committed: it is the pre-built copy for branch-based GitHub Pages — rebuild it with `python3 tools/build.py --docs` when you change `src/`.
- Levels live in the `LEVELS` array (theme, rhino HP, `mutant` behaviours, intro card text); `LEVEL` is the current index. Round 2 = wasteland theme, feints, hot spots, radiation burst, CRT overlay. Round 3 = space theme (`gravity: .5`), horn laser bolts (`bolts`), jet-stomp with landing ring, helmets. Round 4 = two rhinos (`rhinos: 2`, PCR duplicates) on a field twice as wide (`width: 1920`): `AW` is the arena width, `camX` the camera (follows the fighters, `updateCamera()`), the world layer is translated by `-camX` in `draw()` and the background scrolls at half speed; `G.rhinos` is the array (`G.r` = the first), `liveRhinos()` / `rhinoAt(pt, pad)` / `nearestRhino(x)` for hits, `hitRhino(r, p, …)` (the attacking fighter is credited), `updateRhino(r, dt)`, `rhinoBounds(r)` is the whole arena for every rhino (they run past each other; a soft push in `updateRhino()` keeps them from stacking and `passesThrough(r)` lets a charge or jet stomp cross), one HUD bar per rhino, the round is won when every rhino is gone. Punch hit points alternate `handPt` / `farHandPt` with the two punch poses. Round 5 = compositional (`comp: true`, `width: 1440`, `skins: [null,'zebra']`, `huds`, `reveal`, `pacifist: 60`): every player and rhino has a `share` that sums to one (`G.compN` characters at the start), `hp` = share × 100 with `maxhp` 100, `size` = `sizeOf(share)` scales the rig (`rs(r)` = `RS * r.size`, `fighterDraw` multiplies `scl`), `compHit(c, dmg)` moves `dmg / COMP_K` of share to the others in proportion (`compGive`), `compDrop(c)` hands a KO'd character's rest on, a character below `COMP_LIMIT` (6 %) is KO'd; the HUD draws a stacked composition bar and detection-limit ticks. `rhinoLook(p)` picks the animal rig: a revealed `morph`, else an unrevealed `skin` (the zebra looks like a zebra but fights like a rhino). `ANIMALS` also has `moose` (antlers, bell) and `bear` (round ears, stub tail) for round 5's reveal map. `#pacifist=` is honoured only on `LOCAL_BUILD` (file:// or localhost).
- Round 6 = the square (`square: true`, museum theme, `G.square`): the four sides of the room (`SQ`: x 40..920, y 156..470, corner radius 100) are ONE flat track unrolled — every entity keeps its logical `x` and `y`/`jump` and all movement and hit code runs unchanged in that flat frame; only drawing wraps it: `sqBase(lx)` (point, angle, inward normal, corner), `sqPt(lx, h)` (a point h above the wall, pinned to the inner corner above the radius so it never folds), rigid per-entity frames `sqEnterFighter()` / `sqEnterRhino()` (chord between the feet) via `inFrame(e, fn)`, and the world layer clipped to the room. Drawn bodies overlap round a corner where their logical x are further apart, so `foeAt()` backs the 1-D test up with `sqRoomHit()` (the attack point through the attacker's frame into the rhino's); area specials (Godzilla, babysit, slam) scale their reach by `SQ.size`; the KO burst flies in room space (`d.scr`). Players are re-expressed relative to the single rhino every frame (`p.x = r.x + wrapDelta(p.x - r.x)`) so every player-rhino pair is the short way round; never re-centre. Everything is `SQ.size` (.66) and `jumpK(e)` scales jump speed AND gravity with the rig. No walls: `rhinoBounds()` is unbounded, an AI charge ends 200 px past its target (cap 2.5 s), facing holds when the two are opposite on the loop, a trot never goes 'gone'.
- Round 7 = the push (`push: true`, lab theme, `G.push`): letters come from an ordered queue (`typedQ`, fed by keydown without auto-repeat, the touch pads and a co-op guest's `{t:'in', q, i}` with absolute indices), never from the per-frame `pressed` set. `pushTry(u, letter)` against `PUSH_STAGES`; a slip drops the rest of that frame's queue, restarts the unit and locks out for `PUSH.lock`. `updatePlayer` returns right after its timers with a pose; `updateRhino` runs only for ko/gone; `updatePush()` sets every position last. Win at `PUSH.win` (the rhino's centre at the right edge; it then slides over), lose at `pushLoseX()`. Pressure is `(7 + 2*near + min(2, .02 t))`, tiring after 90 s, times the co-op load (each partner weighs `min(1, letters in the last 2.5 s / 5)`), so steady correct typing at ~1.25 letters/s always wins and every round ends. A partner who left is `gone` and drops out of `pushers()`, the lose line and the HUD. The guest enforces its own lockout and banner (a dropped letter is never sent) and the host applies indexed guest letters as they are, so both pages agree letter for letter. No pacifist ending (a code guard, `!G.push`). The snapshot carries `pu`; the guest shows its own row as the host's state plus its not-yet-acknowledged letters (`G.push.pred`).
- Round 8 = cinnamon bun day (`buns: true`, café theme, `G.buns`): J/K/L start `startThrow()` (flat / lob / tray), never `startAttack()`; `hitRhino(r, p, pt, dmg, big, label, o)` returns at once unless `o.bun`, the tray spends its meter itself and its buns carry `noMeter`. Buns live on G (`G.bunsFly`, `G.bunsGround`, `G.bunStats`), hit only via `rhinoAt()` and only while `!G.over`; a missed flat or lob bun becomes food: the rhino forages for it (`forage`) and eats any under its snout (+10 HP, capped), a player walking over it gets +12 meter. A flat bun only flinches the rhino; a lob/tray staggers it with a 1.2 s immunity, never out of 'paw'. `rhinoKO()` is idempotent.
- Rounds 9-11 are IceLab Rumble's own (they were its rounds 5-7 before the Swebits merge). Round 9 = the rerun (`reruns: 4`, `pacifist: 30`): the pacifist reveal chains — `rhinoReveal()` draws from `RERUN_KINDS`; a species with `belongs: true` in `ANIMALS` (reindeer, moose, arctic fox, wolverine, brown bear, lynx, mountain hare — things that belong in a Kiruna sample) or the `reruns`-th pass ends the round (`G.identified` picks the result text); anything else sets `r.rerun`, and `graze` hands over to `rhinoRerun()`, which puts the fight back and resets `G.stageT` (the pacifist clock is per pass: `G.stageT`, not `G.elapsed`). `animalLabel()` says true / false positive on the HUD. Landing a hit ends the chain and the round becomes an ordinary KO fight. Round 10 = `depth: true`: the arena gets a z axis — `Z3` (vanishing point + focal length), `zScale(z)` = `f/(f+z)`, `zPoint(x, z, y)` for floor points, `withZ(z, fn)` draws any 2D rig as a billboard at that depth with distance haze (it wraps `inFrame()`), `drawFloor3D()` lays the ice plane and its grid and `drawLane3D(r)` telegraphs the charge. The rhino's `z` drives the states `zback` → `zaim` → `zcharge` (straight at the camera, dodge sideways or jump). Round 11 = `island: true`: a whole plane instead of a line — `ISLE` is the camera and the island (4800 × 2600 world units, so the fighters come out five times smaller), `isleAt(x, z)` projects, `withIsle(x, z, fn)` billboards a rig at a point on the plane, `isleClamp(e)` keeps everyone on the land, `drawIsland()` paints sea/shelf/beach/snow plus the deterministic pines and boulders of `isleProps()`, and `drawIsleWorld()` depth-sorts everything back to front; `rhinoBounds()` is the island's width and a charge ends once it is past you (like the square). Fighters and rhinos both carry `z`; ← → move across, ↑ ↓ into and out of the screen, and the `hop` action (space, the JUMP pad) jumps — space is `hop` everywhere and counts as a jump off the island; the touch pads swap via `body[data-arena="island"]` and `.tb.iso` / `.tb.flat` (set in `show()`). `inReach(r, q)` gates every attack in rounds 10 and 11 (z ≤ 70 on the front plane; the same line of the island, `ISLE.reach`), inside `rhinoAt()` and in the area specials; `curR` gates the rhino's own hits inside `hitPlayer`. Effects are projected by `fxAt()`, `packP`/`packR`/the fx list carry `z` and the snapshot carries `stageT`/`spawns` for co-op. A minimap sits under the rhino's bar, and `#zoomBtn` (or V) cycles `ZOOMS` = 1 / 1.7 / 2.6×: `applyIsleZoom()` magnifies the projected image around the fighter (`isleCam` lerps after them) and wraps the background as well as the world layer. `depthOn()` / `isleOn()` are false in versus. `#reveal=<kind>` (LOCAL_BUILD only) forces the round-9 species.

- Co-op: `Net` + `coopJoin()` / `netData()`. A room holds up to `NET_MAX` (4) pages: `Net.room` is its member list as its host (`room[0]`) says it is — `setRoom()` sets it, `Net.peer` stays "somebody else is here" (the first other member), `Net.host` = I am room[0] with company. Membership: `hello` carries your room (and `fight`); two pages on their own pair up (the lower id hosts, and the other answers so the host hears it), a host takes a stranger in while there is space and no fight on (`busy` when full, `mid` while fighting), and a host that hears of a room with a lower host is taken over by it, members and all, when everybody fits (`roomFrom()`; the old host tells members left behind with a `room` that leaves them out). A page that will not follow a host that counts it in (mid-fight, or its own host outranks that one) answers with `nofollow` (naming its host; the receiving host lets the member go unless that named host is one it has just seen leave — `Net.left`, a hand-over the member has not noticed yet), and a page that moves rooms says `bye` to its old host. `hello` and `room` carry `seq` (bumped on every change of a page's room): a word from your host older than the last one (`Net.hostSeq`) is stale — it can arrive late over the other transport — and ignored. The host restates `room` every 2 s and hosts in the lobby say hello every 3 s so rooms merge; members send `here` every 3 s and a host drops a member silent for 12 s outside a fight; a member whose host goes silent for 12 s outside a fight is on its own again (`leftRoom()`), and a guest whose fight host has sent nothing at all for 12 s (no snapshot, no `room`) leaves that fight. A new host counts every member as just heard from and starts from nobody ready (only READYs sent to it count, so a hand-over never starts a round without a member that has not noticed it yet); a ready page re-sends its READY to a new host, and every `room` restatement carries `rd` (whom the host has a READY from) so a lost ready / unready heals within 2 s; `fightLost()` only forgets the picks of that fight's players (a benched member's READY stands); `resultNetBits()` recomputes who gets REMATCH / NEXT ROUND when the host changes on the result screen; a page turned away as full says hello again once a room with space says hello. `setRoom()` ends with `maybeStart()` (a hand-over or a departure can leave everybody ready). `memberGone()` (a `bye`, or `peerLost()` → 8 s grace in a fight, per member in `Net.lostIds`) removes a member: the next in line hosts, a departed host ends the fight for its guests (`fightLost()`: back to the fighter screen, nobody ready), a departed guest's fighter is `gone` (`playerLeft()` parks it — idle, lets go of a grabbed rhino, hands a round-5 share on — and it is out of targeting, bolts, drawing, shadows, markers, the camera, the HUD, `alivePlayers()` and `scoreFor()`; in versus `vsSideOut()`). The camera follows who is still standing. With 3-4 players the HUD rows are tighter; in round 6 players 3-4 sit below the room (the ceiling runs at y 156), the round-5 ring bar moves to the bottom centre on a desktop, the co-op rules banner goes below the rows (`G.hudBottom`), and the push HUD shows partners side by side. Ready: `Net.picks[id]`; `maybeStart()` starts when everybody in the room is ready; `coopStart()` takes the last fight's players plus anybody ready (`Net.ids` / `Net.f` = the fight's ids and picks in side order, carried by `start`; a member left out is `benched` until the next one). The host runs `hostTick()` → `update()` with `G.players` in `Net.ids` order (each guest's inputs arrive as `{t:'in'}` into `Net.inputs[id]`, round-7 letters with their own index queue), and `sendSnap()` every 2nd frame to `Net.ids`; the guest (`Net.me` = its index) runs `guestTick()`, sends inputs to the host only, and `applySnap()`. The frame loop picks guest or host from the fight itself (`guestFight()`: `Net.fightG === G` and somebody else is `Net.ids[0]`), never from `Net.peer`, and `myIdx()` is this page's fighter; `packP` / `packR` carry `gone`. Sounds are relayed through `Net.sfxQ` (`[kind, f]` when pitched), crumbs through `cr`, the bun tally through `bs`. `flashA`, `shake` and `impactFrame` fade in `tickAmbient()`, which both pages run (a guest never runs `update()`). Co-op skips the level card, so a round that changes the controls shows its `rules` line for the first 7 s. Two paths: Trystero (`TRYSTERO_URL` = `./vendor/trystero.js`, imported on demand, `relayConfig.redundancy` 10, optional `TURN_SERVERS` / `TURN_CREDENTIALS_URL`) and `relayTransport()` = Supabase Realtime broadcast + presence on the project's `/realtime/v1/websocket` (Phoenix protocol, channel `swebits-rumble:<code>`). the lobby always runs on the relay; every message carries `from` = own id and `to` = the id or list of ids it is for (dropped otherwise); `sendNet(m, ids)` goes to the room (or the members listed) — P2P per member whose data channel is up (`Net.rtcIds`), one relay broadcast addressed to the rest (`sendTo()`); pages never change rooms mid-fight; `fightTimeout()` scopes the KO/result timers to the fight that armed them (`G.fid`). The fighter-screen line shows nostr relays, relay state, the path in use and join errors. Tests inject `window.__coopTransport` (`noRelay: true` to skip the relay; `hubRoom()` in the tests wires any number of pages, a targeted send reaching one page) and mock the relay with `page.routeWebSocket`. Anything that hits or targets a player must loop over `G.players` (see `rhinoTarget()`, `hitPlayer(p, …)`).

Per-round leaderboards: `Scores.load(lvl)` / `Scores.add(entry, lvl)` filter with PostgREST `level=eq.N` (and the local copy, which keeps 200 entries); the HIGH SCORES screen has a `#scoresRound` picker (`openScores(lvl)`, `scoresRound`), a save opens it on the round just played. localStorage is the fallback when the table is unreachable. `board` caches the all-rounds list for the title-screen best and the roster cards (`renderScores` only replaces it when the picker is on all rounds).
